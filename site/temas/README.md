# Temas

Duas versões completas do sistema de design, com as mesmas classes. Trocar
o tema é copiar um destes por cima de `public/assets/css/site.css` e rodar
`python3 build.py`.

| Arquivo | Direção |
|---|---|
| `tema-escuro.css` | **Em uso.** Navy do rodapé como base, latão, cards em vidro |
| `tema-claro.css` | Creme quente e dourado, cards sólidos |

Ao trocar para o claro, ajuste também o `theme-color` em `build.py`
(`#141B29` no escuro, `#FBF8F3` no claro).
